Weather Forecast
Overview
A web app that displays real-time weather information for any city. Users can view temperature, humidity, wind speed, and multi-day forecasts with interactive charts.

Features
City-based weather search (current and forecast)

Live temperature, humidity, and wind data

Error handling for invalid searches or API issues

Data visualizations with charts and tables

Technologies Used
HTML, CSS, JavaScript

OpenWeatherMap API

Setup Instructions

Navigate to the folder:
cd your-repo-name

Open index.html directly or run via local server

Configure your API key in the code (see next section)

Enjoy using the weather app!

How to Get Your Own API Key
This project uses the OpenWeatherMap API to fetch real-time weather data. To use this app, you must obtain your own free API key from OpenWeatherMap.

Steps:

Go to https://openweathermap.org/api

Sign up for a free account

Log in and go to the "API keys" section

Create a new API key and copy the value
