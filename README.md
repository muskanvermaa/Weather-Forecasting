🌤️ Weather Forecasting App

A clean, responsive, and interactive web application that provides real-time weather updates and multi-day forecasts for cities worldwide. Built using HTML, CSS, JavaScript web technologies and powered by the OpenWeatherMap API.

Features
🔍City-Based Search: Look up current weather conditions and detailed multi-day forecasts for any city.   
📊 Live Weather Metrics: Displays real-time temperature, humidity, wind speed, visibility, and sun cycle times (sunrise/sunset).
📈 Data Visualizations: Includes interactive charts and structured tables for quick atmospheric insights.
